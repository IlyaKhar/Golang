# Деплой на Vercel

## ⚠️ ВАЖНО: Vercel для Go

**ТЕОРИЯ:** Vercel в основном для frontend (Next.js, React, Vue)
- Go поддерживается через Serverless Functions
- Это не обычный HTTP сервер!
- Каждый запрос обрабатывается отдельной функцией
- Подходит для API endpoints, но не для долгих соединений

## Альтернативы (лучше для Go):

### 1. **Render.com** (рекомендую!)
- ✅ Простая настройка
- ✅ Бесплатный тариф
- ✅ Автоматический деплой из GitHub
- ✅ Поддержка Go из коробки
- 📁 Уже есть `render.yaml` в проекте

### 2. **Railway.app**
- ✅ Очень простая настройка
- ✅ Бесплатный тариф ($5 кредитов в месяц)
- ✅ Автоматический деплой из GitHub

### 3. **Fly.io**
- ✅ Хорошо для Go приложений
- ✅ Бесплатный тариф
- ✅ Глобальное распределение

## Если всё же хочешь Vercel:

### Шаг 1: Установи Vercel CLI

```bash
npm i -g vercel
```

### Шаг 2: Войди в Vercel

```bash
vercel login
```

### Шаг 3: Деплой

```bash
cd deploy
vercel
```

### Шаг 4: Продакшен деплой

```bash
vercel --prod
```

## Проблемы с Vercel для Go:

1. **Serverless функции** - не подходят для WebSocket, долгих соединений
2. **Таймауты** - функции ограничены по времени выполнения
3. **Холодный старт** - первое обращение может быть медленным
4. **Ограничения** - не все возможности Go доступны

## Рекомендация:

**Используй Render.com** - он идеально подходит для Go приложений:
- Уже есть конфигурация (`render.yaml`)
- Простая настройка через веб-интерфейс
- Бесплатный тариф
- Автоматический деплой

### Быстрый деплой на Render:

1. Зайди на https://render.com
2. Нажми "New +" → "Web Service"
3. Подключи GitHub
4. Настрой:
   - Build Command: `go build -o server ./deploy`
   - Start Command: `./server`
5. Готово! 🚀
