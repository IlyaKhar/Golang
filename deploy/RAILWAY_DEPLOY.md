# Деплой на Railway.app

## 🚀 Railway - отличная альтернатива для Go!

**ТЕОРИЯ:** Railway - современная платформа для деплоя
- ✅ Очень простая настройка
- ✅ Бесплатный тариф ($5 кредитов в месяц)
- ✅ Автоматический деплой из GitHub
- ✅ Отлично подходит для Go приложений
- ✅ Поддержка Docker (опционально)

## Быстрый старт:

### Шаг 1: Регистрация

1. Зайди на https://railway.app
2. Зарегистрируйся через GitHub
3. Нажми "New Project"

### Шаг 2: Подключи GitHub

1. Выбери "Deploy from GitHub repo"
2. Выбери свой репозиторий
3. Railway автоматически определит Go приложение

### Шаг 3: Настройка (автоматическая!)

Railway автоматически:
- ✅ Определит что это Go приложение
- ✅ Установит зависимости (`go mod download`)
- ✅ Скомпилирует приложение
- ✅ Запустит его

### Шаг 4: Настрой переменные окружения (опционально)

В настройках проекта:
- `PORT` - устанавливается автоматически (не нужно!)
- `ENVIRONMENT` - можешь установить `production`

### Шаг 5: Готово! 🎉

Railway автоматически:
- ✅ Задеплоит приложение
- ✅ Дам URL: https://твоё-приложение.up.railway.app
- ✅ Настроит SSL сертификат

## Полезные команды (через Railway CLI):

### Установка CLI:

```bash
brew install railway
```

### Вход:

```bash
railway login
```

### Полезные команды:

```bash
railway status          # Статус проекта
railway logs            # Логи
railway open            # Открыть в браузере
railway variables       # Переменные окружения
```
